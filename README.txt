AKscan - сборка APK
1. Распакуйте архив в НОВУЮ пустую папку (не поверх старой версии).
2. Android Studio: File -> Open -> выберите папку NumberScanner.
3. Дождитесь Gradle Sync. Если Studio предложит обновить Gradle или Android Gradle Plugin - нажмите "Don't remind me" / "Не обновлять".
4. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK: app/build/outputs/apk/debug/app-debug.apk
